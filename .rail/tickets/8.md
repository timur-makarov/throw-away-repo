## Why
Sweep 6, findings F1 to F5 and F7: the guard's new handling of other repositories fails open. A push to
`main` or a merge of this project's pull request passes the guard after `cd /tmp && cd -`, after `popd`,
inside a subshell, with `--git-dir`, or with `-R` naming this project from another directory. The
`--owner` ask rule can be dodged by putting the flag first or abbreviating it. The fixes are made in the
framework (timur-makarov/agentic-framework); this ticket copies the fixed engine in, as section 14 of the
plan describes: diff from the commit in `.rail/SOURCE`, read the framework's CHANGELOG, integrate.

## Done Contract
- Check: `printf '%s' '{"tool_name":"Bash","tool_input":{"command":"cd /tmp && cd - && git push origin main"},"cwd":"'"$PWD"'"}' | .rail/bin/rail hook guard | grep -q '"deny"'`
- Check: `printf '%s' '{"tool_name":"Bash","tool_input":{"command":"cd /tmp && gh pr merge 5 -R timur-makarov/throw-away-repo"},"cwd":"'"$PWD"'"}' | .rail/bin/rail hook guard | grep -q '"deny"'`
