## Request
> An admin should be able to change a product's name through the API. A non-admin gets 403, a missing product 404. The stored write goes through shop/store.py.

## Why
Product names can only be set when a product is created; a typo or a rebrand means deleting and recreating the product. Admins need to rename one in place through the API.

## Done Contract
- Check: `python3 -m pytest -q tests/test_products.py -k rename`
- Check: `python3 -m pytest -q tests/test_auth.py`
- Check: `python3 -m pytest -q && ruff check .`

Behaviour the rename tests must pin: an admin renames an existing product and gets 200; the product list shows the new name with id and cents unchanged; a clerk, viewer or no role gets 403 and the name is unchanged (403 wins even for a missing product); a missing or non-int id gets 404; an empty or non-string name gets 400. Only admins may rename: a new "rename" action in shop/auth.py, because the existing "write" action also belongs to clerks.

## Out of scope
- No change to create or delete of products, or to the response shape of list_products.
- No change to what clerk and viewer may do for existing actions (read, write, delete).
- No stored-data shape change, so no migration.
