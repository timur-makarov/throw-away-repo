## Request
> There are CSV exports for orders and customers in shop/export.py, but none for products. Add one with the same safety rules for cell values, and a test.

## Why
Shop staff can export orders and customers as CSV but not the product list, so they cannot get the catalogue into a spreadsheet. GitHub issue 47 asks for it, with the same cell-value safety as the customers export so that a product name starting with = + - @ cannot run as a formula.

## Done Contract
- Check: `python3 -m pytest -q tests/test_export.py -k products`
- Check: `python3 -m pytest -q`
- Check: `ruff check .`

## Out of scope
- shop/store.py: `store.list_products()` already exists and is used as is.
- The orders and customers exports, their columns and their tests do not change.
- No HTTP route or handler in shop/api.py; this adds the export function only.

## Assumptions
- ASSUMED: columns are `id,name,cents`, named like the product records; the name goes through `_safe`, the integer id and cents are written as is.
- ASSUMED: the new test covers header-only output for no products, one row per product in id order, and a name starting with `=` being prefixed with `'`.
