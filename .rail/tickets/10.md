## Request
> With no orders the orders CSV export returns an empty string. It should still return the header row, so a spreadsheet import does not fail.

## Why
A spreadsheet import fails on an empty file because it has no columns to read. With no orders the export must still carry the header row `id,customer_id,lines,total`, so the import succeeds with zero rows.

## Done Contract
- Check: `python3 -m pytest -q tests/test_export.py -k empty`
- Check: `python3 -m pytest -q`
- Check: `ruff check .`

## Out of scope
- The columns, their order and the row format of `export.orders_csv()` do not change.
- `shop/store.py`, `shop/auth.py` and stored data do not change; no migration.
