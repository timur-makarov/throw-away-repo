## Request
> With no orders the orders CSV export returns an empty string. It should still return the header row, so a spreadsheet import does not fail.

## Why
A spreadsheet import fails on an empty file, so the export must always carry the header row. Reading shop/export.py, `orders_csv` already writes the header before the loop, so this ticket adds the missing test that pins that behaviour, and fixes the code if the test shows otherwise.

## Done Contract
- Check: `python3 -m pytest -q tests/test_export.py -k empty`
- Check: `python3 -m pytest -q tests/test_export.py`

## Out of scope
- The columns, their order and the row format do not change.
- shop/store.py and shop/orders.py are not changed.

## Assumptions
- VERIFIED: with no orders saved, `export.orders_csv()` returns "id,customer_id,lines,total" plus a line ending, as read from shop/export.py and run once.
